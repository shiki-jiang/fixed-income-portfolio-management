# Fixed Income Portfolio Management — Python Research Project

A reproducible, **hypothetical** $100m multi-sector bond-ETF portfolio management case study designed to demonstrate index/portfolio management analytics. 

## Run locally (macOS / PyCharm)

1. Unzip the project and open the folder in PyCharm.
2. In the PyCharm Terminal:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   python -m pytest -q
   python portfolio.py --refresh
   streamlit run dashboard.py
   ```

3. The dashboard opens in a browser. `outputs/portfolio_review.md`, `outputs/performance.html`, and CSV files are also generated.
4. For later runs from locally cached data, use `python portfolio.py` without `--refresh`.

**Internet connection required for the first real-data run.** If Treasury download fails, ETF analysis still runs, with a clear warning. If Yahoo Finance cannot provide prices, the program stops rather than fabricate results. Offline unit tests do not use network calls.

## Files

- `portfolio.py`: Yahoo price downloader, U.S. Treasury downloader, mandate optimizer, backtest, risk, attribution, report export.
- `dashboard.py`: four-tab Streamlit display.
- `config/duration_assumptions.csv`: **illustrative** duration assumptions, replace only with properly sourced dated issuer observations.
- `tests/test_portfolio.py`: deterministic optimization, reconciliation, and lookahead checks.
- `outputs/`: calculated CSVs, PM review, performance chart; regenerated by the analysis command.

## Frozen v1 specification (do not silently change)

| Setting | Value |
|---|---|
| Investment universe | SHY, IEF, TLT, LQD, HYG; AGG as external comparison |
| Initial hypothetical capital | $100,000,000 |
| ETF data window | Jan. 2018 through Oct. 2026 |
| Out-of-sample evaluation | Jan. 2021 through Oct. 2026 |
| Custom benchmark | SHY 15%, IEF 35%, TLT 10%, LQD 30%, HYG 10% |
| Benchmark rebalancing | Monthly, no cost |
| Portfolio rebalance | First available trading day of each month, before that day's return |
| Estimation window | 252 prior trading days; exclude rebalance-day return |
| Covariance | Annualized sample covariance, 10% diagonal shrinkage |
| Optimizer | Convex tracking-error-variance plus L1 turnover penalty; SciPy SLSQP |
| Mandate constraints | Long-only; weights sum 100%; single ETF ≤45%; Treasury ETFs ≥70%; HYG ≤5% |
| Trading cost | 5 basis points of notional bought **and** sold |
| Duration | Manual **illustrative** assumptions; no historical duration claims |
| Treasury data | Official par-yield curve; charted only, not a discount curve |
| Rate stress test | First-order, parallel shock; no convexity or credit spread modeling |

## Calculation assumptions / limitations

- Yahoo-adjusted close prices are a research proxy for total returns, not audited institutional portfolio performance. The entire original Yahoo dataset is not committed to GitHub.
- Transactions are assumed at prior closing prices immediately before the next trading day's return, ignoring market impact beyond the fixed transaction-cost assumption. Rebalancing is monthly, not daily.
- Benchmark is a **custom five-ETF index**, not the Bloomberg U.S. Aggregate Bond Index. AGG is reported separately, not used as the optimization target.
- Weights drift with returns between rebalances; compliance constraints are applied on each rebalance date.
- Duration figures are **illustrative assumptions** and only used for an end-of-test static what-if. No current fund snapshot is applied to historical P&L or portfolio optimization.
- Active contributions exactly reconcile each day including trading costs; sums over many days are not a linked geometric attribution.
- No forecasted alpha, real bond-level execution, credit spread stress, or key-rate duration is claimed.
## Empirical Findings

The out-of-sample backtest covers January 4, 2021, through October 30, 2026.

| Metric | Optimized Portfolio | Custom Benchmark |
|---|---:|---:|
| Cumulative Return | −7.21% | −6.63% |
| Annualized Volatility | 6.78% | 7.01% |
| Maximum Drawdown | −20.05% | −20.74% |

The optimized portfolio achieved slightly lower realized volatility and a smaller maximum drawdown but did not outperform its benchmark. These findings illustrate the trade-off between portfolio constraints, benchmark tracking, and realized performance.

The project demonstrates constrained portfolio construction and risk management rather than a strategy designed to generate alpha.

## Outputs

- `daily.csv`: daily net/gross portfolio returns, benchmark/AGG returns, indexes, drawdowns, turnover, NAVs, trading-cost fractions.
- `weights.csv`: after-return portfolio and benchmark ETF weights.
- `trades.csv`: dates, tickers, previous/target weights, trade notionals, trading costs.
- `attribution.csv`: daily ETF-level active contributions plus cost line.
- `risk.csv`: end-of-test weights, illustrative duration and DV01 contributions.
- `treasury_yields.csv`: Treasury yields where the source successfully downloads.
- `summary.json`, `portfolio_review.md`, `performance.html`.
